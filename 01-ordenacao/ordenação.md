# Ordenação 

Ordenação é o processo de organizar elementos em uma determinada ordem, seja crescente ou decrescente. Existem diversos algoritmos de ordenação, cada um com suas características e eficiências. Alguns dos algoritmos mais comuns incluem:

- **Bubble Sort (Ordenação por Bolha)**: Compara elementos adjacentes e os troca se estiverem na ordem errada. É simples, mas ineficiente para grandes listas.

- **Selection Sort (Ordenação por Seleção)**: Encontra o menor (ou maior) elemento e o coloca na posição correta. Também é simples, mas não é eficiente para grandes listas.

- **Insertion Sort (Ordenação por Inserção)**: Constrói a lista ordenada um elemento de cada vez, inserindo cada novo elemento na posição correta. É eficiente para listas pequenas ou quase ordenadas.

- **Quick Sort (Ordenação Rápida)**: Divide a lista em sublistas menores e ordena recursivamente. É muito eficiente para grandes listas.
