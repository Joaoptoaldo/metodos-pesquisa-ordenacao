# Projeto MVC

Projeto desenvolvido com o objetivo de aplicar o padrão de arquitetura MVC (Model-View-Controller).

Além da organização em camadas, o projeto demonstra a manipulação de listas de números, permitindo gerar dados aleatórios ou sequenciais e medir o tempo de execução das rotinas.


## Estrutura

```text
Projeto/
├── Controller/
│   └── ListaController.cs
├── Model/
│   └── Utilidades.cs
├── View/
│   └── ExibicaoView.cs
└── Program.cs
```


## Como executar

Execute o comando:
```bash
dotnet run
```

## Objetivo

Este projeto foi desenvolvido como atividade prática para compreender a separação de responsabilidades proposta pelo padrão MVC, além de reforçar conceitos fundamentais da linguagem C# e da plataforma .NET.
